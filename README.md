# Victor Wamalwa Portfolio

A simple single-page portfolio website built using HTML,CSS and JavaScript

## Live Demo

[https://victorwamalwa-hub'github.io/victorwamalwa-hub-porfolio/](https://victorwamalwa-hub.github.io/victorwamalwa-hub-portfolio/)


## Features
* Header with navigation links to each section
* About Me section with a short bio and photo
* Skills list rendered from a JavaScript array
* Project cards rendered from a JavaScript array of objects
* Contact section with email and Github link

## Technologies Used
* HTML
